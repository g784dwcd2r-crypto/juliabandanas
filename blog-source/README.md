# Blog source

The journal articles, kept here as plain HTML so they can be written, reviewed
and version-controlled alongside the theme.

`posts.json` holds the metadata for each one — title, handle, tags, excerpt and
SEO description — and the `file` key points at its HTML body.

These files are the source of truth. If a post is edited in the Shopify admin,
paste the change back here so the two do not drift apart.

## Tags

Posts are tagged so the journal's filter strip is useful rather than decorative.
Four tags are in use:

- **Seasons** — how the quarterly model works and what is coming next
- **Guides** — sizing, fit, hanging, choosing
- **Care** — washing, drying, keeping things alive
- **Behind the scenes** — sourcing, checking, opinions about the range

When a season changes, posts one and six are the two most likely to need
rewriting: the first explains the current subject, and the last is specific to it.
