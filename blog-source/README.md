# Blog source

The six launch articles for the journal, kept here as plain HTML so they can be
edited, reviewed and version-controlled alongside the theme.

`posts.json` holds the metadata for each one (title, handle, tags, excerpt and
SEO description); the `file` key points at the HTML body.

These are the source of truth. If you edit a post in the Shopify admin,
paste the change back in here too so the two do not drift apart.
